# **字符设备驱动套路**

1. 定义/动态分配一个cdev变量
2. 初始化cdev变量
3. 注册cdev变量
4. 注销cdev变量

## **用户空间程序调用对应驱动函数：**

1. 确定该驱动程序中的cdev绑定的设备号是多少？（cat /proc/devices 来确定主设备号 + 分析驱动代码确定次设备号）
2. 通过mknod  命令使用主次设备号去创建设备文件
3. 在应用程序中通open 去打开该设备文件，后续read write 等操作也就能够调用到相应的驱动函数
